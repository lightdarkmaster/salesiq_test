This is Massively, a text-heavy, article-oriented design built around a huge background
image (with a new parallax implementation I'm testing) and scroll effects (powered by
Scrollex). A *slight* departure from all the one-pagers I've been doing lately, but one
that fills a few user requests and makes use of some new techniques I've been wanting
to try out. Enjoy it!

Massively features a wide range of styling and layout options, including a responsive
design that adapts to desktop, tablet, and mobile devices. The design is centered around
a massive background image that scales to fit the full height of the browser window,
with a subtle parallax effect that adds depth and visual interest. The design also
features a range of scroll effects, including a fade-in effect for the main content area
and a slide-in effect for the nav panel.

The design is built using a range of modern web development tools and techniques, including
HTML5, CSS3, Sass, and jQuery. The design is fully responsive and has been tested in a
range of browsers and devices.

you can use for pretty much whatever.
